====================================
참고사항
====================================
- URL 사용 방법:
  → 크롬 주소창에 URL을 복사해서 붙여넣고 엔터를 치면 해당 페이지로 바로 이동합니다.
  → Confluence 등에서 URL을 클릭하면 해당 페이지가 열립니다.

- 동적 라우트의 경우 [id] 부분에 실제 ID 값을 넣어서 접근합니다.
  예: /user/faq/1, /user/faq/2, /user/notice/123 등
  → FAQ 상세 페이지를 보려면: http://localhost:3002/user/faq/1 (숫자 1을 원하는 ID로 변경)
  → 공지사항 상세 페이지를 보려면: http://localhost:3002/user/notice/5 (숫자 5를 원하는 ID로 변경)

- 로컬 개발 환경에서는 http://localhost:3002 를 사용합니다.
