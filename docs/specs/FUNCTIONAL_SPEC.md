```

                                    └-> 취소
```

### 포인트 차감 공식

| 캠페인 유형                       | 차감 포인트                                                     |
| --------------------------------- | --------------------------------------------------------------- |
| 배송형 / 방문형 / 기자단 / 미션형 | 추가 지급 포인트 x 모집 인원                                    |
| 구매평                            | (구매 지급 포인트 x 모집 인원) + (추가 지급 포인트 x 모집 인원) |
