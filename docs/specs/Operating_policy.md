## 1. 반려 코드 정의

> 파트너 또는 관리자가 콘텐츠/캠페인을 반려할 때 사용하는 사유 코드.
> 관리자 화면에서 AI 추천을 통해 가장 유사한 코드를 자동 매핑하며, 관리자가 최종 선택/지정 가능.

| 사유 코드 | 구분 | 반려 사유 | 예시 |
|----------|------|----------|------|
| R001 | 콘텐츠 | 구매 정보 불일치 | 영수증 미첨부, 날짜 불일치 등 |
| R002 | 콘텐츠 | 가이드 불이행 | 이미지 수량 부족, 가이드 불충족, 무성의한 내용, 광고성 표현만 있음 등 기타 가이드와 맞지 않는 모든 내용 |
| R003 | 콘텐츠 | 콘텐츠 오류 | 링크 접속 불가, 게시물 삭제됨 |
| R004 | 콘텐츠 | 이미지 도용 의심 | 타인 이미지 도용 시 (외부 크롤링/AI 탐지로 타 계정 이미지 중복 사용 가능성 탐지 — 추후 기술 확인 필요) |
| R005 | 리뷰어/파트너 | 반복 반려 의심 | 동일 사유 반복 반려 3회 이상 |
| R006 | 캠페인 | 부적절한 콘텐츠 요청 | 후기 강요 문구 포함, 과도한 조건 등 |
| R007 | 정산 | 출금 정보 불일치 | 예금주 불일치, 계좌번호 오류 |
| R008 | 기타 | 그외 비매너 행위 | 그외 1~7에 해당하지 않는 행위 |

## 2. 신고 코드 및 패널티 점수표

> 신고 발생 시 부과되는 패널티 점수. 누적 점수에 따라 단계가 결정됨.

### 2.1 리뷰어 신고 코드

| 사유 코드 | 구분 | 신고 사유 | 패널티 점수 | 예시 |
|----------|------|----------|-----------|------|
| W001 | 리뷰어 | 선정 후 취소 | **30** | 선정 후 캠페인 이탈, 미응답 등 |
| W002 | 리뷰어 | 지각 제출 | **10** | 제출 기한 초과 시 시스템 자동 경고 (패널티 누적 가능) |
| W003 | 리뷰어 | 무단 이탈 / 노쇼 | **50** | 승인 후 미션 불이행 (구매/방문/콘텐츠 미작성 등) |
| W004 | 리뷰어 | 노출 기간 불이행 | **30** | 의무 노출 기간 불이행 |
| W005 | 리뷰어 | 수정 요청 불이행 | **30** | 캠페인 콘텐츠 수정 요청 불이행 |

### 2.2 파트너 신고 코드

| 사유 코드 | 구분 | 신고 사유 | 패널티 점수 | 예시 |
|----------|------|----------|-----------|------|
| W006 | 파트너 | 게시 후 삭제 | **20** | 이미 리뷰어가 조회, 신청한 상태에서 일방적인 취소 |
| W007 | 파트너 | 부적절한 캠페인 게시 | **50** | 선정적/불법 이미지, 허위/광고성 문구, 금칙어 포함 (AI 필터링 필수) |
| W008 | 파트너 | 공정위 위반 요청 | **10** | 공정위 필수 문구 삭제 요구, "내돈내산" 강요 등 지속적 발생 시 |

### 2.3 시스템 자동 탐지 코드

| 사유 코드 | 구분 | 신고 사유 | 패널티 점수 | 예시 |
|----------|------|----------|-----------|------|
| W009 | 시스템 | 비정상 요청 반복 | **50** | 동일 요청 반복 전송, 비정상 경로 접근 (자동화 탐지 시 차단) |
| W010 | 시스템 | 중복 계정 탐지 | **50** | 동일 주소/전화번호/IP 또는 동일 계좌 다중 사용 |
| W011 | 시스템 | 콘텐츠 중복 탐지 | **50** | 여러 캠페인에 동일 리뷰 텍스트 제출 |
| W012 | 시스템 | 비정상 접근 기록 | **50** | VPN 사용 또는 자동화된 반복 요청 탐지 |
| W013 | 기타 | 그외 비매너 행위 | **관리자 판단** | 1~12에 해당하지 않는 비매너 행위 |

### 참고: 캠페인 삭제 패널티

파트너가 오픈 후 캠페인을 삭제하는 경우 **W006 (게시 후 삭제, 20점)**이 적용된다. 정당한 사유가 있을 경우 플랫폼 문의를 통해 패널티 면제 가능.

## 3. 패널티 단계 및 정지 기준

> **최종 기준: 기능명세서 v1.2.3 (확정).** PRD와 정지 시점 구조에 차이 있음 (부록 참조).

### 3.1 패널티 단계

| 단계 | 누적 점수 | 상태 | 제재 내용 |
|------|----------|------|----------|
| 경고 | 0 ~ 100 | 일반 활동 가능 | 정지 없음. 1개월간 캠페인 1개 이상 참여 + 무패널티 시 경고 내역 삭제 가능 |
| 주의 | 101 ~ 120 | 자동 일시 정지 | 7일 일시 정지 |
| 주의 | 121 ~ 140 | 자동 일시 정지 | 15일 일시 정지 |
| 주의 | 141 ~ 149 | 자동 일시 정지 | 30일 일시 정지 |
| 정지 | 150 ~ 199 | 장기 정지 | 60일 일시 정지 |
| 정지 | 200 ~ 249 | 장기 정지 | 90일 일시 정지 |
| 정지 | 250 ~ 299 | 장기 정지 | 120일 일시 정지 |
| 정지 | 300 이상 | 영구 정지 | 이용 제한 (로그인 가능, 탈퇴만 가능) |

### 3.2 정지 기준 요약

| 기준 | 적용 |
|------|------|
| 일시 정지 중 | 캠페인 참여/등록 제한, 기존 진행 건만 관리 가능 |
| 영구 정지(이용 제한) | 로그인은 가능하나 이용 제한 화면만 노출, 회원 탈퇴만 가능 (A_M16 → C_M15) |
| 경고 복구 조건 | 경고 조치 후 1개월간 캠페인 1개 이상 참여 + 패널티 0건 |

| B002 | 리뷰어/파트너 | 반복 취소 누적 | W001, W006 3회 이상 | 누적형 자동 차단 |
| B003 | 리뷰어 | 무단 이탈/노쇼 누적 | W003 3회 이상 | 누적형 자동 차단 |
| B004 | 시스템 | 공정위 위반 게시 요청 누적 | W008 + 리뷰어 신고 3회 이상 | 즉시 차단 (정책 위반) |
| B005 | 리뷰어 | 콘텐츠 도용/중복 | R004, W011 3회 이상 | 명백한 도용 확정 시 즉시 차단 |

| B008 | 시스템 | 외부 결제/금전 요구 | 내부 탐지 + 리뷰어 신고 | 즉시 차단 |
| B009 | 리뷰어 | 비매너 행위 | W013, 신고 다수 접수 | 심사 차단 (CS 내역 기반) |
| B010 | 시스템 | 검수 조작 | R005, R006 | 심사 차단 (내부 통제) |

## 5. 캠페인 수정/삭제 정책

### 5.1 수정 가능 범위

| 캠페인 단계 | 수정 가능 항목 | 비고 |
|------------|-------------|------|
| 오픈 예정 | 모든 항목 (상호명 제외) | 수정 버튼 있음 |
| 신청 (오픈 후) | 홍보 링크, 추가 지급 포인트, 참여/제출 옵션, 문의 담당자 휴대폰 번호 | 수정 버튼 있음 |
| 선정 이후 | **수정 불가** | 수정 버튼 없음 |

**추가 지급 포인트 수정 시:** 기존 신청자 포함 전체 적용. 포인트 하향 조정 시 기존 신청자에게 **캠페인 조건 변경 알림** 발송 → 신청 취소 기회 보장.

### 5.2 삭제 정책

| 캠페인 단계 | 삭제 가능 여부 | 패널티 | 비고 |
|------------|-------------|--------|------|
| 오픈 예정 | 가능 | 없음 | 삭제 버튼 있음 |
| 신청 (오픈 후) | 가능 | **W006 (20점)** | 삭제 버튼 있음, 정당한 사유 시 패널티 면제 |
| 선정 이후 | **삭제 불가** | - | 삭제 버튼 없음, 플랫폼 문의를 통해서만 가능 |

### 5.3 선정 이후 비상 대응

선정 이후에는 수정/삭제 버튼이 모두 없다. 이는 의도적 설계로:
- 관리자 인력 리스크 방지 (수정 요청 대응 부담)
- 파트너의 핵심 내용 반복 수정으로 인한 리뷰어 불공정 방지

**심각한 오류 발견 시:** 수정이 아닌 **플랫폼 문의를 통한 삭제 후 재등록**으로 대응.

## 6. 자동 승인 정책

> 파트너가 콘텐츠를 확인하지 않을 경우, 시스템이 자동으로 승인 처리하는 기준.

| 상황 | 자동 승인 시점 | 비고 |
|------|-------------|------|
| 일반 제출 | 캠페인 등록 기간 **마감일 + 7일** | 대부분의 케이스 |
| 지각 제출 | **지각 제출 시점 + 7일** | 등록 기간 이미 만료 상태 |
| 반려 후 재등록 | **재등록 시점 + 7일** | 유예 기간 내 재등록한 건 |

## 7. 반려 후 재등록 정책

> 파트너가 콘텐츠를 반려한 경우, 리뷰어에게 별도 유예 기간을 부여.

| 항목 | 내용 |
|------|------|
| 유예 기간 | 반려 시점부터 **5일** (확정) |
| 기한 내 미등록 시 | **패널티 부과** |
| 등록 기간 마감 전 반려 | 등록 기간 잔여일과 유예 기간 중 **더 긴 쪽** 적용 |
| 파트너 마감 직전 반려 | 리뷰어에게 유예 기간 보장 (리뷰어 귀책 아님) |

**핵심:** 반려는 파트너 판단에 의한 것이므로, 리뷰어에게 충분한 수정 기회를 보장해야 공정. 주말 포함 시 최소 3영업일 확보를 위해 **5일 권장**.

## 8. 연장 정책

### 8.1 연장 유형 및 카운팅

| 연장 유형 | 주체 | 카운팅 | 최대 횟수 | 효과 |
|----------|------|--------|---------|------|
| 일괄 기한 연장 | 파트너 | **별도 (제한 없음)** | - | 전체 리뷰어 대상 +3일 |
| 개별 연장 (파트너 주도) | 파트너 | 리뷰어별 2회 제한에 포함 | 2회 | 해당 리뷰어 +3일 |
| 요청 연장 (리뷰어 요청 → 파트너 승인) | 리뷰어 → 파트너 | 리뷰어별 2회 제한에 포함 | 2회 | 해당 리뷰어 +3일 |

### 8.2 카운팅 예시

- 개별 연장 1회 + 요청 연장 1회 = **2회 소진**, 총 +6일
- 일괄 연장 1회 + 개별 연장 2회 = 총 **+9일** (일괄은 별도)
- 3회째 요청/연장 시도 → **B_M7 (연장 불가 안내)**

### 8.3 UI 반영

- 연장 시 리뷰어 카드의 기한 날짜 실시간 갱신 (예: `2025-11-02` → `2025-11-05`)
- 연장 승인 시 관련 모달: A_M9(최초 1회) / A_M10(2회) → C_M13
- 일괄 연장 시: A_M11 → C_M13

## 9. 구매평 영수증 정책

> 구매평 캠페인에서 구매 영수증과 콘텐츠는 별도로 관리됨.

| 항목 | 콘텐츠 (SNS 리뷰) | 구매 영수증 |
|------|-----------------|-----------|
| 지각 제출 허용 | **허용** (7일 유예) | **불허** |
| 미제출 시 처리 | 지각 제출 기간 경과 후 패널티 | **기간 내 미제출 시 즉시 자동 패널티 + 캠페인 취소** |
| 검수 방식 | 미션 검수 기능 (기본 미션 자동 검수) | 영수증 자동 검수 (주문번호/구매상품/주문금액/배송지) |
| 미통과 시 | 재등록 요청 | B_M11, B_M12 노출 후 재업로드 요청 |

**핵심:** 지각 제출은 콘텐츠에만 적용. 구매 영수증은 지각 제출 대상이 아님.

**구매 여부 판단 기준:** 시스템이 구매 사실을 독립적으로 판단할 수 없으므로, **영수증 제출 여부 = 구매 증명**. 영수증 미제출 시 구매 여부 불문 미이행(W003, 50점) 처리.

## 10. 신고/해제 복구 정책

> 콘텐츠 내역에서 신고 시 "임시 참여 제한" 상태로 전환, 해제 시 원상 복구.

### 10.1 신고 시 처리

1. 해당 리뷰어를 **임시 참여 제한** 상태로 변경
2. 콘텐츠 내역에서 **대기 탭**으로 이동
3. 신고 직전 상태를 스냅샷으로 저장:
   - `previous_tab`: 이전 탭 위치 (확인/완료 등)
   - `previous_content_status`: 콘텐츠 상태 (승인 대기/제출 완료 등)

### 10.2 해제 시 복구

- 관리자가 신고 해제 시 (A_M12 → C_M11)
- **신고 직전 상태로 완전 복원**: 탭 위치 + 콘텐츠 상태 모두 복원
- 예: 확인 탭에서 승인 대기 중이었다면 → 확인 탭으로 복원, 콘텐츠도 그대로

## 11. 무통장 입금 정책

### 11.1 매칭 기준

| 케이스 | 입금자명 | 입금 금액 | 처리 |
|--------|--------|---------|------|
| 정상 | 일치 | 일치 | 포인트 충전 완료 |
| 케이스 A | 일치 | **불일치** | 반려 + **환불 처리** |
| 케이스 B | **불일치** | 일치 | 반려 (CS 대응) |
| 케이스 C | **불일치** | **불일치** | 반려 (CS 대응) |
| 1일 초과 미확인 | - | - | 자동 반려, 신청 내역 자동 삭제 |

### 11.2 환불 계좌

- 무통장 입금 신청 시 **환불 계좌 정보 사전 수집** (기능명세서 14.2 2.4 반영)
  - 환불 계좌: 본인 명의 계좌 (은행, 계좌번호, 예금주)
  - 무통장 입금 신청 폼 내에서 입금자명 하단에 환불 계좌 정보 입력 필드 제공
- 금액 불일치(케이스 A) 감지 시 수집된 환불 계좌로 자동 환불 처리
- 이름 불일치(케이스 B, C)는 시스템 매칭 불가 → CS를 통한 수동 처리

## 12. 사업자등록증 검증 정책

### 12.1 검증 플로우

```
사업자등록번호 입력 (10자리)
        ↓
사업자등록증 이미지 첨부
        ↓
  [OCR 처리 1~3초]
        ↓
┌─ 일치 → "사업자등록번호 확인 완료" (초록색 체크)
├─ 불일치 → "사업자등록번호가 일치하지 않습니다." (에러)
└─ 인식 실패 → "사업자등록증을 인식할 수 없습니다." (에러)
```

### 12.2 처리 기준

| 상황 | 처리 |
|------|------|
| OCR 검증 성공 (일치) | 회원가입 진행 가능 |
| OCR 검증 실패 (불일치) | **가입 차단**, 재입력/재첨부 유도 |
| OCR 인식 실패 | **가입 차단**, 선명한 이미지로 재첨부 유도 |
| OCR API 장애 | "일시적 오류, 나중에 다시 시도해주세요" 안내 |

### 12.3 추가 에러 코드 (신규)

| 코드 | 메시지 | 비고 |
|------|--------|------|
| I_E16 | 사업자등록증을 인식할 수 없습니다. 선명한 이미지를 다시 첨부해 주세요. | 인식 불가 (입력 오류) |
| I_E17 | 입력한 사업자등록번호가 첨부한 사업자등록증과 일치하지 않습니다. | 미일치 (입력 오류) |

### 12.4 권장 API

| API | 처리 시간 | 비고 |
|-----|----------|------|
| Naver Clova OCR | 1~3초 | 국내 사업자등록증 특화 템플릿 있음 |
| Google Cloud Vision | 1~5초 | 범용, 한글 지원 |
| AWS Textract | 2~5초 | 문서 구조 분석에 강함 |

선택사항: 국세청 사업자등록 상태조회 API(무료)와 연동하면 폐업/휴업 사업자 필터링도 가능.

## 부록. PRD ↔ 기능명세서 차이점

> 개발 시 확인이 필요한 두 문서 간 차이점. **기능명세서(v1.2.3)가 최종 확정 기준.**

### 정지 체계 차이

| 항목 | 기능명세서 (v1.2.3) | PRD (v1.0) |
|------|-------------------|------------|
| 주의 단계 (101~150) | 자동 일시 정지 7/15/30일 | 명시 없음 (점수 기반으로만 정의) |
| 정지 단계 (150~) | 일시 정지 60/90/120일 또는 영구 정지 | 영구 정지만 명시 |
| 정지 트리거 | 단계별 진입 시 | 특정 점수 도달 시 (60/90/120/150) |

**기능명세서 기준:** 주의 단계(101~150)에 진입하면 점수 구간에 따라 7/15/30일 자동 일시 정지. 정지 단계(150~)에서는 60/90/120일 일시 정지 또는 영구 정지.

**PRD 기준:** 60점=7일, 90점=15일, 120점=30일, 150~=영구 정지로, 단계와 무관하게 점수 도달 시점에서 정지 발동.

**→ 최종 기준: 기능명세서 (확정). 단계 진입 시점에서 정지 발동, 세부 임계값은 섹션 3.1 참조.**

### 기타 차이 (확정)

| 항목 | 확정 기준 | 기능명세서 | PRD | 비고 |
|------|----------|---------|-----|------|
| 이미지 용량 제한 | **10MB** | 10MB | 5MB | 기능명세서 기준 확정 |
| 이미지 확장자 | **jpg, png, gif** | jpg, png, gif | jpg, png | 기능명세서 기준 확정 |
| 월 최대 출금 | **2,000,000원** | 명시 없음 (추가 반영 완료) | 월 최대 2,000,000원 | PRD 기준 채택, 기능명세서에 반영 완료 |
| 소셜 로그인 | **네이버 + 카카오** | 네이버 + 카카오 | 카카오만 | 기능명세서 기준 확정 |

**→ 전체 확정 완료. 기능명세서(v1.2.3) 기준 + PRD 월 최대 출금 채택.**
