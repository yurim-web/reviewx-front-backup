## 1. 입력 오류 메시지 (I_E)

| 코드      | 상황                   | 메시지                                                                      | 타입 | 사용 화면                               |
| --------- | ---------------------- | --------------------------------------------------------------------------- | ---- | --------------------------------------- |
| **I_E1**  | 휴대폰 중복            | 이미 가입된 휴대폰 번호입니다.                                              | 에러 | 회원가입                                |
| **I_E2**  | 닉네임 중복            | 이미 사용 중인 닉네임입니다.                                                | 에러 | 회원가입                                |
| **I_E3**  | 비밀번호 오류          | 8~16자 영문, 숫자, 특수문자(!@#$%^&\*()-\_=+) 조합으로 입력해 주세요.       | 에러 | 회원가입, 비밀번호 재설정               |
| **I_E4**  | 비밀번호 확인          | 비밀번호가 일치하지 않습니다.                                               | 에러 | 회원가입, 비밀번호 재설정               |
| **I_E5**  | 인증번호 불일치        | 인증번호가 일치하지 않습니다.                                               | 에러 | 회원가입, 아이디/비밀번호 찾기          |
| **I_E6**  | 이름 일치 오류         | 입력하신 정보와 예금주 정보가 일치하지 않습니다.                            | 에러 | 내 정보 수정 > 본인 명의 계좌 정보      |
| **I_E7**  | 아이디/비밀번호 불일치 | 아이디 또는 비밀번호가 일치하지 않습니다.                                   | 에러 | 로그인                                  |
| **I_E8**  | 비밀번호 재설정 오류   | 기존 비밀번호는 사용할 수 없습니다.                                         | 에러 | 비밀번호 재설정                         |
| **I_E9**  | 주민등록번호 오류      | 주민등록번호를 정확히 입력해 주세요.                                        | 에러 | 회원가입, 내 정보 수정                  |
| **I_E10** | 인증번호 시간 초과     | 인증번호 입력 시간을 초과했습니다.                                          | 에러 | 로그인                                  |
| **I_E11** | 정지/탈퇴된 계정       | 정지되었거나 탈퇴된 계정입니다.                                             | 에러 | 로그인                                  |
| **I_E12** | 계정 정보 불일치       | 입력하신 정보와 일치하는 계정을 찾을 수 없습니다.                           | 에러 | 로그인, 계정 찾기, 아이디/비밀번호 찾기 |
| **I_E13** | 아이디 중복            | 이미 사용 중인 아이디입니다.                                                | 에러 | 회원가입                                |
| **I_E14** | 인증번호 5회 초과      | 인증번호 요청 횟수를 모두 사용했습니다. 24시간 후 다시 시도해 주세요.       | 에러 | 회원가입, 아이디/비밀번호 찾기          |
| **I_E15** | 카테고리 중복 불가     | 이미 사용 중인 카테고리명입니다.                                            | 에러 | 카테고리 관리                           |
| **I_E16** | 사업자등록증 인식 불가 | 사업자등록증을 인식할 수 없습니다.`<br>`선명한 이미지를 다시 첨부해 주세요. | 에러 | 회원가입 (파트너)                       |
| **I_E17** | 사업자등록증 미일치    | 입력한 사업자등록번호가`<br>`첨부한 사업자등록증과 일치하지 않습니다.       | 에러 | 회원가입 (파트너)                       |
