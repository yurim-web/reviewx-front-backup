h2. 📌 프로젝트 소개

ReviewX는 리뷰 관리 및 분석을 위한 웹 기반 플랫폼입니다.
사용자들이 효율적으로 리뷰를 관리하고, 데이터를 시각화하며, 인사이트를 얻을 수 있도록 설계된 현대적인 웹 애플리케이션입니다.

h2. 🛠️ 기술 스택 (Tech Stack)

h3. Frontend Framework

|| 기술 || 버전 || 설명 ||
| *Next.js* | 15.5.4 | React 기반의 풀스택 프레임워크. App Router를 사용하여 최신 라우팅 방식 적용 |
| *React* | 19.1.0 | 사용자 인터페이스 구축을 위한 JavaScript 라이브러리 |
| *TypeScript* | 5.x | 정적 타입 검사를 통한 코드 안정성 및 개발자 경험 향상 |

{panel:title=메모|borderStyle=solid|borderColor=#ccc|titleBGColor=#fcf8e3|bgColor=#fefef0}
💡 *Next.js App Router*
→ Next.js 13 이후 도입된 최신 라우팅 시스템
→ Server Components, Streaming, Suspense 등 최신 React 기능 활용
→ 파일 시스템 기반 라우팅으로 직관적인 페이지 구조
{panel}

----

h3. Styling

|| 기술 || 설명 ||
| *CSS Modules* | 컴포넌트별 스타일 격리. CSS 클래스명 충돌 방지 및 모듈화된 스타일 관리 |
| *Modern CSS* | CSS Variables, Flexbox, Grid 등 최신 CSS 기능 활용 |

{panel:title=정보|borderStyle=solid|borderColor=#ccc|titleBGColor=#d9edf7|bgColor=#f4f8fb}
💡 *CSS Modules 사용 예시*

* 빌드 시 자동으로 고유한 클래스명 생성 (스타일 충돌 방지)
{panel}

h3. UI Libraries & Components

|| 라이브러리 || 버전 || 용도 ||
| *Recharts* | 3.5.0 | 차트 및 그래프 시각화. 대시보드, 통계 데이터를 그래픽으로 표현 |
| *react-day-picker* | 9.11.2 | 날짜 선택 UI 컴포넌트. 예약, 기간 설정 등에 사용 |
| *date-fns* | 4.1.0 | 날짜 포매팅 및 계산. 경량화된 날짜 처리 유틸리티 |
| *@toast-ui/react-editor* | 3.2.3 | WYSIWYG 텍스트 에디터. 마크다운 지원, 리치 텍스트 작성 |

{panel:title=메모|borderStyle=solid|borderColor=#ccc|titleBGColor=#fcf8e3|bgColor=#fefef0}
💡 *주요 UI 기능*
* *데이터 시각화*: Recharts를 활용한 인터랙티브 차트 (선 그래프, 막대 그래프, 파이 차트 등)
* *날짜 관리*: react-day-picker와 date-fns 조합으로 직관적인 날짜 선택 및 표시
* *콘텐츠 작성*: Toast UI Editor로 마크다운 기반의 풍부한 텍스트 편집 기능
{panel}

h2. 📁 프로젝트 구조

{code:javascript}
reviewx-web/
├── app/                    # Next.js App Router 디렉토리
│   ├── layout.tsx         # 루트 레이아웃
│   ├── page.tsx           # 홈 페이지
│   └── (routes)/          # 페이지 라우트

├── lib/                   # 유틸리티 함수 및 헬퍼
├── public/                # 정적 파일 (이미지, 폰트 등)
├── styles/                # 글로벌 스타일
├── types/                 # TypeScript 타입 정의
├── package.json           # 프로젝트 의존성 및 스크립트
├── tsconfig.json          # TypeScript 설정
├── next.config.js         # Next.js 설정
└── .eslintrc.json         # ESLint 설정
{code}

h2. 🔄 개발 워크플로우

h3. 1. 프로젝트 시작

{code:bash}
# 1. 저장소 클론 (SourceTree 또는 Git)
git clone https://github.com/donghyun-cmcm/reviewx-web.git

# 2. develop 브랜치로 전환
git checkout develop

# 3. 패키지 설치
npm install

# 4. 개발 서버 실행
npm run dev
{code}

h3. 2. 일상적인 작업 흐름

{noformat}
1. SourceTree에서 develop 브랜치 Pull (최신 코드 가져오기)
2. VS Code에서 코드 작성 및 수정
3. 개발 서버 실행 중 브라우저에서 실시간 확인
4. 변경사항 저장 시 자동 새로고침 (Hot Reload)
5. 작업 완료 후 SourceTree에서 Commit & Push
{noformat}

h3. 3. 코드 품질 관리

* 커밋 전 {{npm run lint}} 실행하여 코드 검사
* TypeScript 에러 확인 및 수정
* 브라우저 콘솔 에러 확인
