# CSS 코딩 가이드라인

## 반응형 스타일 작성 규칙

### 모바일 반응형 미디어 쿼리 형식

모든 모바일 반응형 스타일은 **반드시** 아래 형식으로 작성해야 합니다:

```css
/* 📱 ================================================================================================

모바일 반응형 스타일 (max-width: 768px)

================================================================================================ 📱 */

@media (max-width: 768px) {
  /* 모바일 스타일 내용 */
}
```

### 규칙
- 브레이크포인트: `max-width: 768px` 사용
- 주석 형식을 정확히 따를 것
- 이모지와 구분선을 포함할 것
